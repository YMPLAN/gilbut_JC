# 길벗 일본어 회화 어휘 연습 스튜디오 · 선생님 PC용

Google 시트, Apps Script, 계정 가입, 개인 API 키 없이 시작합니다.

## 3단계 사용법

1. **학생 관리 → 학생 등록 화면 열기**: 선생님이 이 컴퓨터의 화면을 제시하면 학생이 학급·번호·이름을 직접 입력합니다. 등록 후 바로 연습하거나 다음 학생에게 화면을 넘길 수 있습니다. 같은 학생의 재등록은 기존 기록을 유지하며 다른 이름의 같은 학급·번호는 덮어쓰지 않습니다. 선생님의 명단 일괄 등록도 가능합니다.

학생 등록 화면은 다른 학생 명단을 표시하지 않는 입력 화면이며, 교사 인증이나 원격 수집 기능은 아닙니다. 다른 컴퓨터에서 주소만 열어 등록하면 선생님 컴퓨터로 자동 전송되지 않습니다.
2. **회화 연습**: 학생과 활동 선택 → 원음 듣기 → 녹음 → 자신감 선택 → 저장.
3. **학급 대시보드**: 학생별 기록을 확인하고 녹음을 들으며 발음 명료성·유창성·의미 전달을 4단계로 평가합니다.

## PC에서 실행

[웹 프로그램](https://ymplan.github.io/gilbut_JC/)의 **설정·백업 → PC용 실행 파일 받기**를 누릅니다. 받은 HTML 파일을 Chrome 또는 Edge로 엽니다. 서버나 개발 도구 설치는 필요하지 않습니다.

파일에는 1단원 117개 문항, 교재 원음 116개, 현재 명단과 기록이 포함됩니다. 자기 이름 문항은 기기 일본어 합성 음성을 사용합니다. 선생님용 파일은 학생에게 전달하지 마세요.

원음 듣기·녹음·교사 평가·대시보드는 인터넷 없이 사용할 수 있습니다. 마이크 권한과 브라우저 저장 공간을 허용해야 합니다. 자동 문장 인식과 Gemini 평가에는 인터넷이 필요합니다. 일반 Chrome/Edge 창에서 같은 파일 이름·위치를 유지해 사용하세요.

## 학생이 각자 연습할 때

학생 관리의 **학생용 파일**을 만들어 해당 학생에게 전달합니다. 그 학생 정보와 교재만 들어 있고 다른 학생 명단·기록·API 키는 넣지 않습니다. 학생은 연습 후 **이 학생의 결과 파일 받기**로 제출하고, 선생님은 **학생 결과 가져오기**로 모읍니다. 중복 기록은 추가하지 않고 기존 교사 평가는 유지합니다. 다른 학급 공간 파일은 거부합니다.

원격 로그인·자동 네트워크 수집은 없습니다. 학생용 화면 구분은 인증이나 부정행위 방지 기능이 아닙니다. 제출 결과는 교사가 확인합니다.

## 기본 평가와 선택 AI

- 기본: 녹음·학생 자신감·교사 4단계 평가·학급 대시보드.
- 무료 자동 인식: 연습 화면에서 선택하면 지원 브라우저로 일본어 문장을 인식합니다. 개인 API 키는 필요하지 않지만 인터넷이 필요하며 음성이 브라우저 제공업체 서버로 전송될 수 있습니다. 미지원·실패는 미평가로 두고 녹음은 저장합니다.
- **문장 일치도는 발음·음소·억양 정확도 점수가 아닙니다.** 글자를 비교하므로 한자·가나 표기에도 영향을 받습니다.
- 선택 Gemini: 설정·백업에 키를 입력하고 ‘이번 실행에서 사용’을 누릅니다. 녹음 후 AI 버튼을 누를 때 음성을 Google로 보내 연습용 피드백을 받습니다. 시트·서버 설치가 필요 없습니다. 기본 모델은 gemini-3.8-flash이며 음성 입력 지원 모델로 바꿀 수 있습니다.
- 키는 메모리에만 두고 파일·백업·브라우저 영구 저장소에 넣지 않습니다. AI 전송은 매번 확인합니다. 녹음과 목표 문장만 보내며 명단 필드는 보내지 않습니다. 말한 이름은 음성에 포함될 수 있습니다.
- API 비용은 선생님 계정에 발생할 수 있습니다. AI 점수는 참고 자료이며 공식 성적이 아닙니다. 문장 일치도·교사 평가·AI 점수를 구분해 표시합니다.

## 백업과 복원

수업 후 **설정·백업 → 전체 백업 파일 받기**를 이용하세요. 기록·녹음은 현재 브라우저 저장 공간에 보관합니다. 브라우저 데이터 삭제나 다른 컴퓨터·브라우저로 옮기기 전에 백업하세요. 복원은 학교·학생·기록 수 확인 후 현재 공간 전체를 교체합니다. 학생 결과 가져오기는 새 기록만 추가합니다.

GitHub는 프로그램·교재 배포에만 사용하며 학생 명단과 녹음을 업로드하지 않습니다. 기존 Google 시트 기록은 자동 이전하지 않습니다. 이전 Google 연결 소스는 저장소에 보존되어 있지만 새 기본 화면에서는 사용하지 않습니다.

## 구성 및 검증

- simple/: 새 화면, 로직, 단일 파일 생성 원본
- index.html: 새 기본 진입 화면
- studio/lessons.json 및 studio/audio/: 기존 교재와 원음
- 배포 파일에는 테스트 명단·테스트 녹음·API 키가 없습니다.
- 중복 수집, 학급·학생 구분, 평가 보존, 잘못된 파일 거부, 미평가/0점 구분, 최신 교사 평가 집계, 단일 HTML 문법, 원음 116개의 원본 바이트 일치를 검사했습니다.
- 브라우저에서 합성 테스트 음원으로 녹음·저장·재실행·교사 평가를 확인했습니다. 실제 학생 발음 평가의 타당도 검증은 아닙니다. PC 파일 직접 열기는 검증 도구가 허용하지 않아 확인하지 못했습니다. 실제 Gemini API 호출도 개인 키가 없어 수행하지 않았습니다.
