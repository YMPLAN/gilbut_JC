# ことば 랩 · 일본어 말하기

길벗 고등학교 일본어 회화 1단원의 15개 표현을 활용하는 녹음·학습 대시보드 시제품입니다.

## 접속

https://ymplan.github.io/gilbut_JC/

기본 주소에서 새 프로그램이 바로 열립니다. /studio/ 주소는 기본 주소로 이동합니다.

## 사용 방법

예문 듣기 → 녹음 → 다시 듣기 → 자가 평가 선택 → 학습 기록 저장 순서로 사용합니다. 표현당 3회 저장하면 연습 완료로 표시됩니다. 대시보드에서 누적 연습, 학습한 날, 최근 7일 현황과 복습 추천을 확인합니다.

## 파일 구성

- index.html: 새 프로그램 첫 화면
- studio/app.js: 녹음·자가 평가·대시보드
- studio/style.css: 화면 디자인
- studio/scoring.mjs: 연습용 문장 일치도 계산
- studio/lessons.json: 교재 표현과 안내
- studio/index.html: 기존 연습실 주소에서 기본 주소로 이동
- .github/workflows/pages.yml: main 브랜치 변경 시 GitHub Pages 배포

교재를 수정하려면 studio/lessons.json을 편집합니다. 앱에서 다른 교재를 불러온 경우 ‘기본 교재로 돌아가기’를 누르세요.

## 저장과 평가 범위

- GitHub Pages는 사이트와 교재 파일을 제공합니다. 학생 로그인, 서버 DB, 기기 간 동기화는 연결되지 않았습니다.
- 학생 기록은 현재 브라우저에 저장합니다. 공유 기기에서는 기록이 섞일 수 있습니다. 기록을 JSON으로 내보낼 수 있습니다.
- 녹음은 최대 30초이며 자동 업로드하지 않습니다. 재녹음·표현 변경·페이지 종료 시 사라지므로 필요한 파일은 다운로드하세요.
- 예문은 기기에 설치된 일본어 합성 음성으로 재생합니다. 교재 원음이 아닙니다.
- 선택적 브라우저 음성 인식은 제공업체 서버로 음성을 전송할 수 있습니다. 지원 여부는 기기와 브라우저에 따라 달라집니다.
- 문장 일치도는 인식 문자열과 기준 문장의 비교이며 발음·억양 평가 점수가 아닙니다.
- 기존 퀴즈 화면과 코드는 현재 버전에서 제거되었습니다. 새 연습실 기록은 유지되며 이전 퀴즈 진도는 사용하지 않습니다.

Chrome 또는 Edge에서 HTTPS 주소로 접속해 마이크 권한을 허용하세요. 실제 서비스의 학생별 온라인 성취도와 정밀 발음 평가에는 별도의 인증·DB·평가 서비스 연결이 필요합니다.
