# はじめまして! 일본어 회화 첫걸음

길벗 일본어 회화 교과서 1과 `はじめまして`를 바탕으로 만든 로그인 없는 학생용 웹앱 프로토타입입니다.

## 학습 설계
- 뜻 이해 → 문장 덩어리 보기 → 천천히 듣기 → 따라 말하기
- 핵심 표현 카드
- 상황별 하루 인사말
- 문장 퍼즐과 단어 바꾸기
- 브라우저 음성합성을 활용한 일본어 듣기
- Web Speech API가 가능한 브라우저에서 일본어 말하기 인식
- 선택형 역할 회화
- 3분 마무리 퀴즈
- localStorage 기반 기기 내 진도 저장(로그인/서버 저장 없음)

## 실행
`index.html`을 브라우저에서 열면 됩니다.

GitHub Pages를 사용하는 경우 저장소 Settings → Pages에서 `main` 브랜치 루트를 배포 대상으로 선택합니다.

## 주의
브라우저 음성 인식은 브라우저/OS 환경에 따라 지원 범위가 다릅니다. Chrome 계열 브라우저를 권장합니다.

## 녹음·학습 대시보드 (ことば 랩)

- 기존 학습 홈: https://ymplan.github.io/gilbut_JC/
- 녹음 연습실: https://ymplan.github.io/gilbut_JC/studio/
- 교재 데이터: [studio/lessons.json](studio/lessons.json)

홈의 ‘녹음·학습 대시보드 열기’ 버튼으로 이동합니다. 예문 듣기 → 마이크 녹음 → 다시 듣기 → 자가 평가 선택 → 학습 기록 저장 순서로 사용하세요. 표현당 3회 저장하면 연습 완료로 표시됩니다. 녹음 파일은 다운로드할 수 있으며 자동 업로드하지 않습니다.

### 저장소 구성과 수정

기존 index.html은 회화·퍼즐·퀴즈, studio/index.html은 연습실 화면, studio/style.css는 디자인, studio/app.js는 녹음·대시보드, studio/scoring.mjs는 문장 일치도 계산입니다. studio/lessons.json의 표현을 수정하면 main 브랜치의 기존 Pages 배포 작업이 실행되어 사이트에 반영됩니다. 학습 설정에서 다른 교재를 불러온 경우 ‘기본 교재로 돌아가기’를 누르면 저장소 기본 교재를 사용합니다.

### 학생에게 안내할 사항

- Chrome 또는 Edge에서 HTTPS 사이트를 열고 마이크 접근을 허용하세요. 예문 듣기는 기기의 일본어 합성 음성을 사용하며 교재 원음이 아닙니다.
- 선택한 경우에만 브라우저 음성 인식을 시작합니다. 음성이 브라우저 제공업체 서버에 전달될 수 있습니다.
- 문장 일치도는 인식된 문자와 기준 문장의 비교이며, 발음·억양 정확도 점수가 아닙니다. 한자·가나 표기 차이에도 영향을 받습니다.
- GitHub Pages는 웹사이트와 교재 파일을 제공합니다. 학생 로그인, 서버 DB, 기기 간 기록 동기화는 구현되지 않았습니다.
- 학습 기록은 현재 브라우저에 저장합니다. 공유 기기에서는 기록이 섞일 수 있습니다. 기존 퀴즈 진도(jc1)와 새 연습실 기록은 별도로 저장됩니다.
- 녹음은 재녹음·표현 변경·페이지 종료 시 사라집니다. 필요한 녹음은 직접 다운로드하세요. 대시보드 기록은 JSON으로 내보낼 수 있습니다.
- 과거 localhost 시제품 기록은 GitHub Pages로 자동 이전되지 않습니다.

실제 서비스에서 학생별 온라인 성취도를 제공하려면 별도의 인증·DB 및 일본어 발음 평가 서비스를 연결해야 합니다. GitHub 공개 저장소에 학생 기록·녹음이나 API 비밀 키를 올리지 않습니다.
