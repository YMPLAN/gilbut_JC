# ことば 랩 · Google Classroom Records

길벗 고등학교 일본어 회화 1단원 기반의 녹음·학습 대시보드입니다.

- 사이트: https://ymplan.github.io/gilbut_JC/
- 선생님 설치 안내: [Google 연결 안내](google-apps-script/setup.html)
- 상세 운영 안내: [SETUP.md](google-apps-script/SETUP.md)

## 시작 방법

사이트를 열면 선생님 연결 / 학생 연결 / 연결 없이 체험 안내창이 표시됩니다. 입력하지 않아도 마이크 녹음, 다시 듣기, 자가 평가와 브라우저 내 기록을 이용할 수 있습니다.

선생님은 본인 소유 Apps Script를 한 번 배포한 후, 시작 안내창에 Google 시트 주소와 배포 주소·교사 코드를 입력합니다. 개인 Gemini API 키·모델은 선택 사항입니다. 입력한 API 키는 인증된 선생님 서버의 Script Properties에 저장하며 GitHub·브라우저 저장소에는 저장하지 않습니다. 학생 접속 코드와 교사 접속 코드도 현재 페이지 메모리에만 유지합니다.

## Google 시트와 학급 대시보드

교사는 학급 대시보드에서 학생을 등록해 개인 코드를 발급·재발급하고 접속을 중지할 수 있습니다. 학생은 자신의 기록만 조회·저장합니다. 서버가 생성한 일시와 등록된 학생·교재 정보를 사용합니다. 다른 학생 기록 또는 전체 명단을 학생 응답에 포함하지 않습니다.

시트의 Students / Lessons / Records 탭을 사용합니다. 실제 시트에 연결하기 전에는 학급 데이터나 AI 점수를 만들어 표시하지 않습니다. 새로고침하면 현재 시트 행을 다시 읽어 학급·학생·기간별 참여 현황, 완료 표현, 자가 평가, AI 참고 점수와 변화를 계산합니다. 점수 변화는 같은 문장·모델·기준끼리 비교합니다.

## 음성 평가

학생이 선택하고 동의한 경우에만 녹음을 WAV로 변환해 선생님의 Gemini API로 전송합니다. 결과는 AI 학습 피드백과 참고 점수이며, 검증된 음소·억양 평가나 공식 성적이 아닙니다. 무음·불확실·오류 응답은 평균 점수에서 제외합니다. 음성 파일 자체는 Google 시트/Drive에 보관하지 않습니다. 브라우저 음성 인식의 문장 일치도와 Gemini 참고 점수는 별개입니다.

학생별 하루 AI 15회, 기록 100회, 학급 AI 기본 300회로 제한합니다. 동일 요청을 재시도하면 같은 기록을 반환해 중복 호출을 막습니다. 문서당 학생 500명·기록 10,000행을 지원합니다. 서버 시간과 할당량 날짜는 한국 시간입니다.

## 저장소 구조

- index.html: 홈페이지
- studio/app.js, scoring.mjs: 기존 로컬 녹음·문장 비교
- studio/classroom.js, classroom.css: 시작 안내창, 연결, 학생 전송, 교사 대시보드
- studio/analytics.mjs: 실제 기록 집계
- studio/lessons.json: 기본 교재
- google-apps-script/Code.gs, appsscript.json: 교사가 본인 계정에 배포할 서버
- .github/workflows/pages.yml: GitHub Pages 자동 배포

## 검증 범위

권한 분리·학생 기록 격리·중복 방지·음성 형식·무효 AI 응답·완료율·비교 가능한 변화 계산을 로컬 모의 테스트합니다. 실제 Google 시트 쓰기와 유료 Gemini 호출은 선생님이 개인 서버 및 키를 연결한 후 테스트 학생으로 확인해야 합니다. Google Apps Script 연결은 학교 정책 및 브라우저 네트워크 환경의 영향을 받습니다.

## 교재 원음

1단원 15쪽 기본 표현 7개와 16쪽 듣고 말하기 어휘 8개의 원본 MP3를 `studio/audio/`에 포함합니다. 원본 `punit1/015_01.html`, `016_01.html`의 `data-audio` 번호에 따라 연결했습니다. 느리게/보통 재생, 재생 중지, 문항 이동·녹음 시작 시 원음 중지를 지원합니다. 파일은 사용자가 제공한 교사용 자료에서 가져왔으며 수정하지 않았습니다. 원음 정보가 없는 사용자 교재에는 기기 합성 음성임을 표시합니다. 기존 문항 ID와 평가 대상 문장은 유지되어 학생 기록 및 Google 시트 Lessons와 호환됩니다.
