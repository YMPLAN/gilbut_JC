우리 반 Google 시트 연결하기

선생님의 시트와 Gemini API로 운영합니다. 아래 설정은 선생님 Google 계정에서 한 번 진행합니다.

1. 비공개 관리용 시트를 준비하세요

선생님 소유의 Google 시트에서 확장 프로그램 → Apps Script를 여세요. 다음 파일의 내용을 각각 적용합니다.

서버 코드 내려받기 · 설정 파일 내려받기 · 상세 설명

시트 URL의 /d/ 와 /edit 사이가 SHEET_ID입니다. 시트와 스크립트 편집 권한은 학생에게 공유하지 마세요.

2. 교사 접속 코드를 먼저 설정하세요

가장 간단한 방법은 아래에서 코드를 생성해 스크립트 속성에 TEACHER_CODE만 먼저 입력하는 것입니다. 시트 주소와 Gemini 키는 프로그램 시작 안내창에서 입력할 수 있습니다.

수동으로 모두 설정하려면 프로젝트 설정 → 스크립트 속성에 아래 값을 입력해도 됩니다. GitHub에는 키를 올리지 마세요.

속성입력할 값
SHEET_ID선생님 시트 문서 ID
GEMINI_API_KEY선생님의 개인 Gemini API 키
GEMINI_MODEL계정에서 지원하는 오디오 입력·구조화 출력 모델 ID
TEACHER_CODE아래에서 생성할 교사 접속 코드
DAILY_AI_LIMIT학급 하루 AI 요청 한도. 기본 300회

아직 생성하지 않았습니다.

이 버튼은 현재 기기에서 코드를 생성하며 서버에 보내지 않습니다. 생성한 값을 안전하게 보관하고 TEACHER_CODE 속성에 입력하세요.

3. 초기화하고 웹 앱으로 배포하세요

  1. TEACHER_CODE만 입력했다면 초기화 실행은 건너뛰세요. 시트는 시작 안내창에서 연결할 때 초기화됩니다.
  2. 이미 SHEET_ID까지 수동 설정했다면 setupClassroom을 실행해도 됩니다. Google 권한 요청은 선생님이 확인·승인하세요.
  3. 배포 → 새 배포 → 웹 앱을 선택합니다.
  4. 실행 사용자는 나, 액세스는 모든 사용자(익명 포함)로 설정합니다. 시트 공개 공유는 필요하지 않습니다. 서버가 교사·학생 코드로 접근을 검사합니다.
  5. /exec로 끝나는 배포 주소를 복사합니다.

학교 정책상 익명 웹 앱 배포가 금지되어 있다면 이 방식은 사용할 수 없습니다. 관리자 정책을 따르는 별도 서버가 필요합니다.

4. 앱에서 연결하고 학생 코드를 발급하세요

앱 시작 안내창에 시트 주소, 배포 주소, 교사 접속 코드를 입력하세요. 원하면 Gemini API 키와 모델 ID도 입력하고 시트·API 연결하고 시작을 누르세요. 키는 선생님 서버에만 저장됩니다. 연결을 건너뛰고 체험할 수도 있습니다. 학급 대시보드에서 학생을 등록하면 개인 코드가 한 번 표시됩니다.

학생에게는 사이트 주소 + 배포 주소 + 개인 학생 코드를 전달하세요. 교사 코드와 API 키는 전달하지 않습니다.

학생은 녹음·자가 평가 후 시트 저장 또는 Gemini 피드백을 선택합니다. 선생님은 대시보드에서 새로고침해 실제 기록을 확인합니다.

처음에는 테스트 학생으로 확인하세요

실제 Google 계정 연결은 위 배포 후에 활성화됩니다. 짧은 녹음을 보내 기록 저장과 AI 결과를 확인하세요. Gemini 점수는 참고용이며 공식 성적이나 정밀 발음 측정치가 아닙니다.

녹음 파일 자체는 시트에 보관하지 않습니다. API 평가를 선택하면 Google Gemini에 전송됩니다. 학생 정보와 피드백은 선생님 시트에 저장됩니다.

이미 연결한 선생님: 회화 문항 업데이트

최신 Code.gs로 교체·저장한 뒤 Apps Script에서 배포 → 배포 관리 → 수정 → 새 버전 → 배포를 선택하세요. 기존 배포 주소와 스크립트 속성은 유지합니다.

프로그램에서 선생님으로 연결한 뒤 학급 대시보드 → 새 교재 문항을 시트에 추가를 누르세요. 기존 학생·학습 기록은 유지하고 Lessons에 누락된 문항만 추가합니다. 기존 문장이 다르면 덮어쓰지 않고 확인 안내를 표시합니다.
