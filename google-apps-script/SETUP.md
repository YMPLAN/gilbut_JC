# 선생님 Google Sheets · Gemini 연결 안내

웹 화면만 배포한 상태에서는 시트 저장이나 Gemini 평가가 실행되지 않습니다. 각 선생님이 본인 Google 계정에서 아래 설정을 한 번 완료해야 합니다. API 키를 학생 페이지, GitHub, 채팅에 붙여 넣지 마세요.

## 시작 안내창으로 연결하기 (권장)

1. 아래 설명대로 Apps Script 코드와 매니페스트를 적용하고, 스크립트 속성에 무작위 TEACHER_CODE만 먼저 설정합니다.
2. setupClassroom을 실행하지 않고 웹 앱으로 배포합니다(실행 사용자: 나, 액세스: 모든 사용자). 권한 요청은 선생님이 확인·승인합니다.
3. 사이트를 열면 시작 안내창이 표시됩니다. Google 시트 주소, 배포 주소, 교사 접속 코드를 입력합니다. Gemini API 키와 모델은 선택입니다.
4. ‘시트·API 연결하고 시작’을 누르면 교사 인증 후 시트 탭을 초기화하고, 입력한 Gemini 키를 선생님 서버 속성에 저장합니다. 브라우저에는 저장하지 않습니다. 키를 입력하지 않으면 기존 키가 있는 경우 유지하고, 없는 경우 시트 저장만 연결합니다.
5. 설치를 나중에 하려면 ‘지금은 연결 없이 사용하기’를 누르세요. 이후 학습 설정에서 안내창을 다시 열 수 있습니다.

아래의 수동 설정 방식도 지원합니다.

## 1. 학생 기록용 Google 시트 준비

선생님 소유의 비공개 Google 시트를 만들거나 기존 관리용 시트를 선택합니다. 시트 주소의 `/d/`와 `/edit` 사이 값이 문서 ID입니다. 학생에게 시트를 공유할 필요가 없습니다.

시트에서 **확장 프로그램 → Apps Script**를 엽니다. 기본 코드를 지우고 이 폴더의 [Code.gs](Code.gs) 내용을 붙여 넣습니다. 프로젝트 설정에서 매니페스트 파일 표시를 선택하고 [appsscript.json](appsscript.json)을 적용합니다.

## 2. 스크립트 속성 입력

Apps Script → 프로젝트 설정 → 스크립트 속성에서 다음 값을 입력합니다.

| 속성 이름 | 값 |
| --- | --- |
| SHEET_ID | 선생님의 Google 시트 문서 ID |
| GEMINI_API_KEY | 선생님 개인 Google AI Studio의 Gemini API 키 |
| GEMINI_MODEL | 선생님 계정에서 사용 가능한 오디오 입력·구조화 출력 지원 모델 ID |
| TEACHER_CODE | 무작위로 생성한 24자 이상 교사 접속 코드. Gemini 키와 다른 값 |
| DAILY_AI_LIMIT | 학급 전체 하루 AI 요청 상한. 생략하면 300회 |

모델 ID는 Google AI Studio에서 확인하세요. 현재 Google 오디오 문서의 예시는 `gemini-3.8-flash`를 사용하지만, 계정의 지원 여부와 사용 한도를 확인한 뒤 지정해야 합니다. 모델을 바꾸면 학생의 점수 변화 비교는 같은 모델의 기록끼리만 이루어집니다.

스크립트 편집 권한이 있는 사람은 속성을 열람할 수 있으므로 프로젝트 편집 권한을 학생과 공유하지 마세요.

## 3. 초기화 및 배포

1. 함수 선택에서 `setupClassroom`을 선택하고 실행합니다. Google 권한 요청 내용을 확인하고 선생님이 승인합니다.
2. 시트에 Students, Lessons, Records 탭이 생성됩니다. 이미 있으면 헤더를 확인하고 내용을 유지합니다. 같은 이름의 다른 용도 탭이 있으면 새 관리용 시트를 사용하세요.
3. **배포 → 새 배포 → 웹 앱**을 선택합니다.
4. 실행 사용자: **나(선생님)**. 액세스: **모든 사용자(익명 포함)**. 이 설정은 코드 인증 요청을 받을 공개 API 주소를 만드는 것이며, 시트 공유 설정을 공개로 바꾸는 것이 아닙니다. 학생 기록 조회·저장은 서버에서 개인 코드로 제한합니다.
5. 학교 정책에서 익명 웹 앱을 허용하지 않으면 관리자의 정책을 따르세요. 이 연결 방식은 그런 환경에서 사용할 수 없으며 별도의 인증 서버가 필요합니다.
6. 생성된 `/exec`로 끝나는 웹 앱 주소를 복사합니다. `/dev` 주소는 사용하지 않습니다.
7. 앱의 **학습 설정 → Google Sheets 연결**에 배포 주소와 TEACHER_CODE를 입력하고 ‘선생님으로 연결’을 누릅니다.

API 키를 바꿀 때는 스크립트 속성의 GEMINI_API_KEY만 수정합니다. 코드를 수정했을 때는 배포 관리에서 새 버전으로 다시 배포합니다. 교사 코드를 바꾸면 이전 코드는 더 이상 사용할 수 없습니다.

## 4. 학생 등록과 사용

학급 대시보드에서 학급·이름(또는 별명)을 입력하고 학생 코드를 발급합니다. 발급된 코드는 다시 조회할 수 없으며 분실 시 재발급합니다. 학생에게 사이트 주소, 웹 앱 배포 주소, 개인 학생 코드만 전달합니다. 교사 코드와 Gemini 키는 전달하지 않습니다.

학생은 학습 설정에서 학생으로 연결한 뒤, 녹음 → 다시 듣기 → 자가 평가를 선택합니다. ‘연습 기록만 시트에 저장’은 음성을 전송하지 않습니다. ‘Gemini 피드백 받고 저장’은 동의 체크 후 녹음과 기준 문장을 Gemini로 보냅니다. 학급·학생 식별 정보는 Gemini 요청에 포함하지 않습니다. 녹음 중 스스로 이름을 말한 경우 그 내용은 음성에 포함될 수 있습니다.

한 녹음의 저장을 재시도해도 같은 요청 ID를 사용해 중복 저장·중복 AI 호출을 방지합니다. 평가 요청이 타임아웃되면 기록을 새로 불러와 확인하세요. `pending`이 오래 남으면 Apps Script 실행 내역을 확인하고 새로운 녹음으로 재시도합니다. AI 오류·평가 보류 기록에는 점수를 부여하지 않습니다.

## 5. 데이터와 대시보드

- Students: 학생 ID, 이름, 학급, 접속 코드 해시, 활성 상태, 등록일
- Lessons: 표현 ID, 기준 문장, 읽기, 그룹. 기본 교재를 초기화 때 가져옵니다. 이후 GitHub 교재를 바꾸었다면 이 탭의 교재도 교사가 맞춰야 합니다.
- Records: 서버 생성 일시, 학생/표현, 길이, 자가 평가, 처리 상태, AI 참고 점수·명료도·유창성, 피드백, 전사, 모델, 평가 기준 버전. match_score 열은 향후 호환용이며 현재 비워 둡니다.
- 녹음 파일 자체는 시트나 Google Drive에 저장하지 않습니다. 외부 AI 서비스의 데이터 처리 정책은 선생님의 API 계정 조건을 따릅니다.
- 대시보드는 ‘시트에서 새로고침’할 때 실제 행을 다시 읽습니다. 학급·학생·기간으로 필터링할 수 있습니다.
- 참여율은 선택 범위의 등록 학생을 분모로 합니다. 완료 표현은 선택 기간에 3회 이상 저장한 표현입니다. AI 점수 없는 기록은 평균에서 제외합니다.
- 학생 변화는 같은 표현·기준 문장·모델·루브릭의 첫 점수와 마지막 점수 차이를 표현별로 구해 평균합니다. 공식 성적·검증된 발음 측정치가 아닙니다.
- 학생별 하루 AI 15회, 전체 기록 100회, 학급 AI 기본 300회. 날짜는 한국 시간 기준입니다. 실패한 AI 요청도 한도에 포함합니다.
- 문서당 학생 최대 500명, 기록 최대 10,000행. 이 한도를 넘으면 조용히 누락하지 않고 오류를 안내합니다. 이전 기록을 선생님이 별도 문서에 보관하고 학기별로 문서를 구분하세요.
- 시트 헤더를 바꾸거나 요청 ID를 삭제하면 동작·중복 방지에 영향을 줍니다. 앱이 기록 중일 때 Records 탭을 정렬·행 삭제하지 마세요. 필터 보기 사용을 권장합니다.

## 연결 점검

‘응답을 확인하지 못했습니다’가 나오면 `/exec` 주소, 배포 액세스, 학교 정책, 네트워크를 확인합니다. 이 연결은 브라우저에서 Google Apps Script ContentService로 text/plain POST를 보내고 JSON 응답을 읽습니다. 응답을 읽지 못했다고 저장 성공으로 표시하지 않습니다. API/시트 권한 오류는 선생님 Apps Script 실행 내역에서 확인하세요. 키나 학생 기록을 오류 메시지·로그에 붙이지 마세요.

실제 시트와 Gemini API 연결 검증은 선생님 배포 후 테스트 학생과 짧은 녹음으로 수행합니다. 화면에 0명·0회 또는 미연결로 표시되는 것은 샘플 기록을 넣지 않았기 때문입니다.

참고: [Apps Script 웹 앱](https://developers.google.com/apps-script/guides/web), [속성 서비스](https://developers.google.com/apps-script/guides/properties), [Gemini 오디오 이해](https://ai.google.dev/gemini-api/docs/audio), [구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output).

## 회화 활동이 추가된 버전으로 업데이트

이미 연결한 선생님은 최신 Code.gs로 코드를 교체하고 저장한 다음 **배포 → 배포 관리 → 수정 → 새 버전 → 배포**를 실행합니다. 기존 배포 주소와 스크립트 속성을 유지하세요. 프로그램에서 선생님으로 연결하고 **학급 대시보드 → 새 교재 문항을 시트에 추가**를 누릅니다. Students와 Records는 그대로 유지하며 Lessons에 누락된 ID만 추가합니다. 기존 ID의 문장이 다르면 덮어쓰지 않고 충돌 수를 표시합니다. 처음 설치하는 시트는 최신 전체 교재로 시작합니다.

27쪽 내 이름 말하기는 학생이 적용한 일본어 이름을 실제 평가 문장과 기록에 반영합니다. 이름 자체의 맞춤법 채점이 아니라 표시된 문장을 읽는 발음 연습입니다.

문항 동기화는 같은 ID·같은 문장의 활동 분류를 최신 값으로 정리합니다. 기존 문장이나 학생 기록을 덮어쓰지 않습니다.
